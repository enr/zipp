$Small, sharp tools for zip archives.

zipp is a set of command-line utilities to work with zip files: list their contents, timestamp new archives, and add files to existing ones — including nested archives.

// THE TOOLBOX

Three commands, one job each.

01 zipw

Add a file to an existing archive — including nested writes into a jar inside a war inside an ear. Interactive, flag-driven, or YAML-configured.

zipw -f README.md -i archive/readme.md -z app.zip
02 zipls

List a zip's contents with sizes, timestamps, grep/exclude filters and sorting — a quick, readable view into any archive.

zipls -s -t --sort size app.zip
03 zipts

Zip a directory into an archive whose name carries a timestamp suffix — handy for snapshots and backups, with exclude patterns.

zipts -x 'vendor/*' -o /tmp/backups .
